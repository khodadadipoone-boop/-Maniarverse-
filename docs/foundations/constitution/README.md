This folder holds the documents that each declare themselves the constitution or the top authority on Maniar's behavior. All four were added at the founder's request (2026-10-26). No document titled exactly "Maniarverse Constitution" (5-article or 8-article versions) was found in Google Drive.

## ⚠️ تضادهای باز · Open conflicts (not resolved — founder decision required)

۱. **ساعت و تشخیص احساس · Watch and emotion detection.**
Character Bible v3.0 (فصل ۴ و ۶): رنگ ساعت «بر اساس وضعیت عاطفی کودک» تغییر می‌کند. ↔ AI-001 §2، §4، §6: ساعت مانیارِ همراه هیچ حکمی نمی‌دهد و در لحظه‌های سخت «هیچ تغییر رنگی» ندارد؛ PRD فاز ۱: بدون تشخیص احساس و بدون سنسور.
Character Bible v3.0 says the watch color changes with the child's emotional state; AI-001 forbids verdict colors and any color change when the child struggles; PRD Phase 1 excludes emotion recognition and sensors.

۲. **لایک و دیس‌لایک · Like/Dislike.**
Character Bible v3.0 لایک و دیس‌لایک را «حرکت امضا» می‌داند. ↔ AI-001 §2، §5: ژست‌های تأیید/رد (G-05/G-06) اصلاً برای مانیارِ همراه کاربرد ندارند.
Character Bible v3.0 lists thumbs up/down as a signature move; AI-001 says Approval/Disapproval gestures never apply to Companion Maniar. (Narrative Maniar on YouTube still uses them.)

۳. **دنیاها · Worlds.**
Character Bible v3.0: Calm، Joy، Inner، **Respect World**. ↔ Interaction Bible v1.0: Calm، Joy، Inner + آینده: **Natural World**، **Kindness World**. ↔ DL-004: فاز ۱ فقط یک دنیای شروع.

۴. **«چالش» صبحگاهی و برچسب احساسی · Morning "challenge" and emotion tags.**
Interaction Bible §۶ «پیشنهاد یک چالش کوچک» و §۷ «برچسب احساسی» دارد؛ باید با قانون «بدون فشار و بدون ارزیابی» در AI-001 و PRD (FR-C02) چک شود.

۵. **سن و ظاهر مانیار · Maniar's age and look.**
Character Bible v3.0: سن احساسی ۴ تا ۶ سال، ظاهر نرم و غیرکارتونی. AI-001: «لباس رسمی تیره، ساعت روی مچ چپ» (CB-001 §2). مانیارِ روایی یوتیوب: پسر ۷ ساله با مونوکل طلایی.

۶. **ترتیب اعتبار · Order of precedence.**
AI-001 خودش را بالاتر از Interaction Bible می‌داند، ولی Character Bible v3.0 هم خودش را «قانون اساسی» می‌نامد و قدیمی‌تر از جدایی مانیارِ همراه و مانیارِ روایی است. بنیان‌گذار باید ترتیب اعتبار را مشخص کند.
AI-001 ranks itself above the Interaction Bible, while Character Bible v3.0 also calls itself the constitution and predates the Companion/Narrative split. The founder must set the order of precedence.
