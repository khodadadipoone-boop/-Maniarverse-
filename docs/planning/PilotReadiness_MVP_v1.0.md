MANIARVERSE MVP
Pilot Readiness
Version: 1.0
________________________________________
1. Purpose
This document defines the conditions that must be met before the Maniarverse MVP is released for pilot testing.
The pilot will be conducted in two stages:
Stage 1: 2–3 families 
Stage 2: 10 children 
________________________________________
2. MVP Readiness Criteria
The MVP is considered ready for pilot testing when all of the following conditions are satisfied.
Parent Experience
•	Parent can register successfully. 
•	Parent can verify their email. 
•	Parent can log in successfully. 
•	Parent can reset their password. 
•	Parent can create and manage child profiles. 
________________________________________
Child Experience
•	Child can complete the First Meeting. 
•	First Meeting is shown only once. 
•	Child can select a world. 
•	Child can complete the core experience. 
•	Child can pause or exit safely. 
________________________________________
Memory Capsule
•	Child can create a Memory Capsule. 
•	Photos, videos, and notes are saved correctly. 
•	Parents can view saved memories. 
________________________________________
Parent Summary
•	Parent can view the child summary. 
•	Summary information is displayed correctly. 
________________________________________
Security
•	Parents can access only their own child profiles. 
•	Unauthorized access is rejected. 
•	Child media is protected. 
________________________________________
Stability
•	No critical bugs remain. 
•	All core user flows complete successfully. 
•	No data loss occurs. 
•	No application crashes occur during normal use. 
________________________________________
3. Stage 1 Pilot (2–3 Families)
The first pilot aims to validate the complete user journey with a small number of families.
Success criteria:
•	Parents complete onboarding without assistance. 
•	Children understand the experience without confusion. 
•	Memory Capsules are successfully created. 
•	No critical technical issues occur. 
•	Parents report that the experience is clear and safe. 
________________________________________
4. Stage 2 Pilot (10 Children)
The second pilot evaluates usability and engagement with a larger group.
Success criteria:
•	Most children complete the experience. 
•	Some children voluntarily return on another day. 
•	Parents report a positive experience. 
•	No major usability issues are identified. 
•	The product remains stable during testing. 
________________________________________
5. Exit Criteria
•	The pilot is considered successful when:
•	Core functionality works reliably. 
•	Pilot feedback is positive. 
•	No critical defects remain unresolved. 
•	The product is approved for the next development phase.
