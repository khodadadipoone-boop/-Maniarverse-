Parent Registration
Acceptance Criteria
•	Parent can create a new account using a valid email and password. 
•	Duplicate email addresses are rejected. 
•	Invalid input is validated. 
•	Verification email is sent successfully. 
•	Parent account is created in the database.

Acceptance Criteria

Child Profile
Acceptance Criteria
•	Parent can create a child profile. 
•	Required fields are validated. 
•	Child profile is linked to the authenticated parent.

First Meeting
Acceptance Criteria
•	First Meeting is shown only once for each child. 
•	After completion, first_meeting_completed_at is stored. 
•	Returning children skip First Meeting.
