## Handover & Maintenance Rules
1. **Source of Truth:** Colors defined here directly dictate CSS/Tailwind theme variables in frontend applications (`apps/parent-web`, `apps/child-app`).
2. **Immutability:** Do not overwrite existing color files when color values change. Introduce `v2.0` files and append them to this log.
3. **Tracking:** Record any subsequent designer who alters or refines this color system in this log.
