## Handover & Maintenance Rules
1. **Source of Truth:** These component specifications directly dictate the creation of React/Next.js UI components in `apps/parent-web/components/`.
2. **Immutability:** Existing component files must not be overwritten when redesigning. Create `v2.0` files and add new entries to this table.
3. **Tracking:** Any updates or new component additions by future designers must be documented in this log.
